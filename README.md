# Feed It Out Productions Android App

<p align="center">
  <img src=".github/logo.png" alt="feeditout-productions-android-app logo" width="128" />
</p>

An Android app that lists the apps published by Feed It Out Productions.

## What it does

It downloads the project list from feeditout.com and shows each app with
its icon, title, description, version and download count. It also shows
whether each app is installed and up to date.

## Tech

- Java for Android

## Building

This is an Eclipse Android project (`AndroidManifest.xml`,
`default.properties` and `proguard.cfg`). Import it into Eclipse with
the Android Developer Tools, or build it with the Android SDK.
